# Redis Drainability Profiling - Validation Test Output
# Date: 2026-02-20
# Build: Symmetric malloc/free fastpath instrumentation

## Test Setup
- Redis 7.2.12 with libdrainprof integration
- jemalloc 5.3.0 with ENABLE_DRAINPROF
- Instrumentation: imalloc_fastpath() + free_fastpath()

- Still 0 drainable (0% DSR)

- Freed ~195K objects (48% reduction in live data)
- Reclaimed 0 slabs (0% improvement in drainability)

## Conclusion

Structural fragmentation confirmed:
- Deleted 50% of keys (50K deletions)
- Freed 195,641 objects (403K → 208K live)
- DSR remained 0% (no slabs became drainable)
- All 256 slabs still pinned by scattered allocations

The remaining 50K keys are distributed uniformly across all slabs at
~813 objects/slab, preventing any slab from becoming fully empty and
reclaimable. This demonstrates genuine structural fragmentation where
freed memory at the application layer cannot be reclaimed at the
allocator layer due to scattered surviving allocations.
